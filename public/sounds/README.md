# Sounds

Archivos placeholder de 36 bytes (MP3 silenciosos válidos) para que `use-sound` no
tire 404 en runtime. El cableado del trofeo "¡Suena bien!" está hecho — solo hace
falta reemplazar estos archivos por audio real:

- `tap.mp3` — click en botones y navegación
- `success.mp3` — login exitoso
- `error.mp3` — credenciales inválidas / error de red
- `swipe.mp3` — cambio de tarjeta en el carrusel

No se incluyen MP3 reales en el repo por tema de licencia/copyright.
